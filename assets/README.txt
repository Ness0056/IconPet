ICONPET full asset pack for Mohamed

Included folders:
assets/idle          -> front idle frames
assets/play_stretch  -> stretch/play frames
assets/r             -> side idle right frames
assets/s             -> sleep frames
assets/wl            -> walk left frames
assets/wr            -> walk right frames

All sprites were cropped to content, resized to a visible height of 140 px, and placed on transparent canvases with bottom alignment so the cat stays visually stable during animation.
